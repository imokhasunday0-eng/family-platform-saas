# Development Phases

## Phase 1 — Foundation
- Project setup, design system tokens, shadcn/ui base components
- Auth (email/password + Google OAuth via Better Auth)
- Prisma schema + first migration
- Dashboard shell + navigation

## Phase 2
- Calendar (month/week/day/agenda, recurring events, drag-and-drop)
- Meal Planner (weekly plan, recipes, pantry, auto grocery generation)
- Grocery List (shared real-time list, categories, purchased status)

## Phase 3
- Chores (assignment, recurrence, points, leaderboard)
- Budget (income, expenses, categories, savings goals, bills, charts)

## Phase 4
- Family Chat (real-time messaging, reactions, attachments)
- Notes (rich text, checklists, categories)

## Phase 5
- Notifications (push, email, in-app)
- Settings (family/user profile, theme, permissions, data export)

## Phase 6
- Performance optimization, security hardening
- Testing, documentation, production deployment
